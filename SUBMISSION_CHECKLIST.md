# Generative AI submission checklist

## Included and locally verified

- [x] Executed `generative_model.ipynb`, runs top to bottom.
- [x] Real human-created MNIST, not reused from prior capstones.
- [x] Data inspection, representative raw/binary images, shapes and preprocessing.
- [x] Complete PyTorch VAE, reparameterization, loss, optimizer and training loop.
- [x] Ten-epoch training progress with reconstruction and KL diagnostics.
- [x] All 64 prior decoder means plus all 64 literal Bernoulli samples displayed.
- [x] Specific strengths/failures tied to actual sample IDs.
- [x] Reconstructions distinguished from unconditional generations.
- [x] Five-sentence final notebook summary.
- [x] `module_summary.pdf` with all seven required sections.
- [x] Fourteen-page report uses actual figures, metrics and example failures.
- [x] Contextual ethical discussion and responsible-use limits.
- [x] At least two credible sources, including scholarly ACM and VAE/evaluation sources.
- [x] APA 7 in-text citations and alphabetized references.
- [x] Own results are reported directly, not formally cited as external sources.
- [x] Actual working-environment `requirements.txt` freeze.
- [x] All four unchanged data files, source URLs, hashes and attribution notice.
- [x] Twelve local tests and exact fresh-environment reproduction.
- [x] Report pages visually reviewed; plain explanation on page 5 avoids jargon.
- [x] AI assistance disclosed and no invented metrics or external generated images.

## Before classroom submission

- [ ] Edward reviews, understands and personalizes the notebook and report as
      required by the course's academic-integrity policy.
- [ ] Edward checks the specific classroom upload instructions and uploads the
      submission ZIP. Nothing in this repository submits to Udacity automatically.
- [ ] If supplying a repository URL, give the draft PR/development branch while
      it remains unmerged, or approve merging the completed work into `main`.
      The initial `main` branch alone does not contain the capstone submission.

The ZIP includes the required files and original dataset; no separate data
download is needed when it is extracted intact. Rebuilding the report from
source needs the original course APA template and LibreOffice; opening the
supplied PDF/DOCX does not.
